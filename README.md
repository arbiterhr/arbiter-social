# arbiter-social

Images for Arbiter HR social media posts. Independent HR support for health and social care. https://arbiterhr.co.uk

- `images/` finished post pictures, named by post date (YYYY-MM-DD-day.jpg)
- `brand/` the Arbiter HR logo used on the pictures
- `tools/make_card.py` makes the black and gold picture cards

This folder is public. It holds post pictures only. No passwords, keys, personal data or client information.
